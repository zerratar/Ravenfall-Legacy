# 🛠️ Ravenfall v0.9.5.2 hotfix

Sorry, streamers with lots of players! 0.9.5.1 could fail to bring your players back and kept flashing "Connection to the server lost". This update fixes it:

✅ **Players are restored again**, however many you have.
✅ **No more connection drops** from that big restore.
✅ **"Loading items" no longer gets stuck** if the game starts while the server restarts.

The game updates itself when you start it. If you had the problem, restart the game after updating. Your players come back from your save, and if the save lost them, the game offers to restore the players the server remembers from your stream.

📜 Details and downloads: https://github.com/zerratar/Ravenfall-Legacy/releases/tag/v0.9.5.2a-alpha

Thank you for your patience and for reporting it so quickly! 💜
