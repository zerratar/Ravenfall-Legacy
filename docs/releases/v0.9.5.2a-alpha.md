# Ravenfall v0.9.5.2a Release

**A hotfix for streams with many players: players are restored again, and the connection to the server no longer keeps dropping.**

> **Please update now** if your stream has a lot of players. Everything from [v0.9.5.1a](https://github.com/zerratar/Ravenfall-Legacy/releases/tag/v0.9.5.1a-alpha) is included.

---

## Fixed

- **Players were not restored, and "Connection to the server lost" kept flashing**, on streams with hundreds of players. The server's answer with all the restored players was larger than the connection allowed, so the game dropped the connection, asked again after reconnecting, and got the same answer again. The connection now carries messages of any realistic size, and a large one that takes a while to arrive is no longer taken for a dead connection.
- **Streams on the previous version could not reconnect** after the server restarted for the update. Older versions are let back in again and told that an update is out, as before 0.9.5. (Fixed on the server; no update needed for this one.)
- **"Loading items" could stay up for good** when the game started while the server was restarting. The game now tries again by itself.
