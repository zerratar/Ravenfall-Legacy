# v0.9.7.0a release checklist

Everything that has to happen, in order, to ship v0.9.7.0a. Written 2026-11-19; tick items off as they are done.
Nothing here is deployed yet: until the release, v0.9.7 work runs on the local server and the dev DB only.

## 1. Before the release build

- [ ] **Signed-in playtest with real chat** (the streamer logged in, the live bot, a few viewers):
  - [ ] `!tower`: join, the floor quests, `!tower boss`, the boss intro and fall, a clear, the town, `!tower climb`,
        votes while the streamer is away, `!tower leave`, `!tower close`, **Tower open to chat** off
  - [ ] `!pets`, `!tame metalon`, `!pets hatch`, `!pets evolve`
  - [ ] `!tree`, `!learn`, `!loadout`, `!respec` (the Tome of Forgetting), the character's skills used in fights
  - [ ] `!gems`, `!gems enchant`, `!gems combine`, `!socket`, `!unsocket`
  - [ ] the What's new window on first start, Effect words over fights, the hero HUD (orbs, skill bar)
  - [ ] earlier work never tried signed in: clan logo and cape upload (website Look tab, admin page), the website
        character customizer's save, a boat look's equip round trip
- [ ] Fix what the playtest finds.
- [ ] Bump the version to **0.9.7.0a** in the editor (Player Settings > Version). ProjectSettings.asset is not in git:
      the version lives on the build PC (it still says 0.9.6.2a).
- [ ] `tools/items/fill-missing-icons.cs` (copies the website's item icons into Assets/Resources/Items, which is not in
      git). On 2026-11-19 all 850 items had icons in both places.
- [ ] Resources that are not in git and have to be on the build PC: `Assets/Resources/Tower/Boss Taunts.asset`
      (`tools/tower/tower-boss-taunts.cs` makes it again).

## 2. Build and test the update path

- [ ] Ravenfall > Release > Build Windows and Linux (CoreCLR, not Development).
- [ ] **Test the update path on a real build** (never tested outside the editor): an installed 0.9.6.1a with
      "Download updates early" picks up the new version in the background, the Update now card starts the patcher
      from the finished download, and the game comes back on 0.9.7.0a. Test against a local copy of the release files
      before publishing.
- [ ] RavenNest.Tools `package` (F2) -> `Build-release-packages/v0.9.7.0a-alpha/`.
- [ ] Release notes: `docs/releases/v0.9.7.0a-alpha.md` and `-discord.md` (drafts written 2026-11-19; update them with
      whatever lands before the release).

## 3. Server and bot (ask before each deploy)

RavenNest master is 55 commits ahead of production (since the 2026-11-07 deploy of the coin resend and town hall push):
combat v2 gear stats and enchantments, skill trees, battle pets and Taming, gems, the tower (both bands), the
website's /combat, /skill-trees, /pets and /tower pages, the 0.9.7 release news, Vitality and armor health, pet eggs.

- [ ] Back up the production database.
- [ ] **TokenSigningKey: decide.** Setting `AppSettings:TokenSigningKey` for the first time invalidates every
      session and connection token, so every streamer signs in again. Whether a 0.9.6 client recovers from that by itself
      is untested: try it against the local server first, or leave the key out of this release (the user said
      2026-11-02 to leave it for now).
- [ ] `lanlink-cli run SERVER deploy-ravennest` (graceful stop). DatabaseSchema adds the new tables and columns at
      startup (Taming as skill 17, StreamTower, TowerClear, pets, gems, skill builds); it does not add indexes.
- [ ] Check after: website, /tower, /pets, /skill-trees, /combat, api/items, the news post appears once a 0.9.7 game
      connects (it is seeded when the server first sees game version 0.9.7).
- [ ] `lanlink-cli run SERVER deploy-ravenbot` (the chat pacer, `!tower`, `!pets`, `!tame`, `!tree`, `!learn`,
      `!loadout`, `!respec`, `!gems`, `!socket`, `!unsocket`). Check it reconnects to Twitch and games connect.

**0.9.6 clients after the server deploy** (checked 2026-11-19): they keep working. New events (skill builds, streak
eggs) are ignored, new fields are skipped, no new item types, Taming is a skill index they never send, the server does
not check combat. Two things to know: the website shows the new health numbers (Vitality) while 0.9.6 games show the
old; and the server's `!enchant` can roll the new magical attributes, which do nothing in a 0.9.6 game, so the server
deploy and the release should happen the same day.

## 4. Publish

- [ ] The user creates the GitHub release `v0.9.7.0a-alpha` and uploads the packages. From the moment it is published
      the server's release watcher (every 5 minutes) makes new 0.9.6 sessions update first; streams already running get
      the update notice and stay connected.
- [ ] Discord post by hand (`-discord.md`).
- [ ] Check on the first stream after publishing: the update honours (Trailblazer, Early Birds) fire, the What's new
      window opens, the release news is on the website.
