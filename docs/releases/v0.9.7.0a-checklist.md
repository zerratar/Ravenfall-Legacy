# v0.9.7.0a release checklist

Everything that has to happen, in order, to ship v0.9.7.0a. Written 2026-11-19; tick items off as they are done.
Nothing here is deployed yet: until the release, v0.9.7 work runs on the local server and the dev DB only.

## 1. Before the release build

- [ ] **Signed-in playtest with real chat** (the streamer logged in, the live bot, a few viewers):
  - [ ] `!tower`: join, the floor quests, `!tower boss`, the boss intro and fall, a clear, the town, `!tower climb`,
        votes while the streamer is away, `!tower leave`, `!tower close`, **Tower open to chat** off
  - [ ] `!pets`, `!tame metalon`, `!pets hatch`, `!pets evolve`
  - [ ] a tame: taming stops after it ("Taming stops there"), and `!tame` again starts the next one
  - [ ] a daily quest on day two or later of a streak: the coins and experience paid match what the offer showed
        (the streak bonus was never paid before 2026-11-21)
  - [ ] a quest paying a skill at 999: a Small book for a daily, a Medium one for a chain, a Large one for a weekly
  - [ ] **class gear** (docs/class-gear-design.md): Flax from Farming and Hide while fighting actually drop; weave
        Linen, tan Leather, craft a piece; a robe has no pauldrons; hat, hood and helm show the right amount of head;
        `!equip all` while training Magic, Healing, Ranged, Attack and Defense picks the fitting line and leaves a
        miner in plate; sockets in a class hat; transmog a plate helmet into a hood on the website
  - [ ] **attachments**: a tier 6 or higher set shows its plume, wings, belt parts and (with the cape hidden) its
        cloak or pack; the helmet toggle hides the head attachments with the helm
  - [ ] `!toggle cape`: hides a personal cape and a clan cape, the armor's back piece shows instead, the choice is
        still there after rejoining; `!toggle cape` again brings the cape and its clan logo back
  - [ ] tower votes: one `!tower boss` from a viewer starts the fight a minute later; a second active viewer
        finishes it at once; `!tower close` needs most of the active players
  - [ ] website while signed in: the gem picker (add, replace, remove), the Pets tab, the dashboard's auto join
        panel, the admin Set coins tool, a boat with a look shows its own picture
  - [ ] `!tree`, `!learn`, `!loadout`, `!respec` (the Tome of Forgetting), the character's skills used in fights
  - [ ] `!gems`, `!gems enchant`, `!gems combine`, `!socket`, `!unsocket`
  - [ ] the What's new window on first start, Effect words over fights, the hero HUD (orbs, skill bar)
  - [ ] earlier work never tried signed in: clan logo and cape upload (website Look tab, admin page), the website
        character customizer's save, a boat look's equip round trip
- [ ] Fix what the playtest finds.
- [ ] Bump the version to **0.9.7.0a** in the editor (Player Settings > Version). ProjectSettings.asset is not in git:
      the version lives on the build PC (it still says 0.9.6.2a).
- [ ] `tools/items/fill-missing-icons.cs` (copies the website's item icons into Assets/Resources/Items, which is not in
      git). On 2026-11-19 all 850 items had icons in both places.
- [ ] Resources that are not in git and have to be on the build PC: `Assets/Resources/Tower/Boss Taunts.asset`
      (`tools/tower/tower-boss-taunts.cs` makes it again).

## 3. Server and bot (ask before each deploy)

RavenNest master is 55 commits ahead of production (since the 2026-11-07 deploy of the coin resend and town hall push):
combat v2 gear stats and enchantments, skill trees, battle pets and Taming, gems, the tower (both bands), the
website's /combat, /skill-trees, /pets and /tower pages, the 0.9.7 release news, Vitality and armor health, pet eggs,
auto join patron perks and the daily limit (7ca2c59d; 0.9.6 games get the perks and limit too, through the old call),
and the admin "Set coins" tool on a character's inventory.

- [ ] Back up the production database.
- [ ] Class gear needs nothing run by hand: the 240 items, Flax, Hide, Linen, Leather, their recipes and drops are
      made at startup (`GameData.ClassGear.cs`), the 40 new materials are numbers in an existing column, and the
      cape toggle is a user property. Check the log line "Class gear: N item(s) created" after the first start.
      The first start also merges the "Woollys Bell" copies production has collected (5fc64e18): check its log line.
- [ ] **TokenSigningKey: decide.** Setting `AppSettings:TokenSigningKey` for the first time invalidates every
      session and connection token, so every streamer signs in again. Whether a 0.9.6 client recovers from that by itself
      is untested: try it against the local server first, or leave the key out of this release (the user said
      2026-11-02 to leave it for now).
- [ ] `lanlink-cli run SERVER deploy-ravennest` (graceful stop). DatabaseSchema adds the new tables and columns at
      startup (Taming as skill 17, StreamTower, TowerClear, pets, gems, skill builds); it does not add indexes.
- [ ] Check after: website, /tower, /pets, /skill-trees, /combat, api/items, the news post appears once a 0.9.7 game
      connects (it is seeded when the server first sees game version 0.9.7).
- [ ] `lanlink-cli run SERVER deploy-ravenbot` (the chat pacer, `!tower`, `!pets`, `!tame`, `!tree`, `!learn`,
      `!loadout`, `!respec`, `!gems`, `!socket`, `!unsocket`, `!auto limit`, `!toggle cape`). Check it reconnects to Twitch and
      games connect.

**0.9.6 clients after the server deploy** (checked 2026-11-19): they keep working. New events (skill builds, streak
eggs) are ignored, new fields are skipped, no new item types, Taming is a skill index they never send, the server does
not check combat. Two things to know: the website shows the new health numbers (Vitality) while 0.9.6 games show the
old; and the server's `!enchant` can roll the new magical attributes, which do nothing in a 0.9.6 game, so the server
deploy and the release should happen the same day.

  cape); how the 40 materials look in the game's light at every tier.
- The daily streak bonus through a real finished daily; a real tame stopping the taming.

  from real chat, and the saved choice has not been checked after a rejoin.

Decisions made by Claude that the owner may want to change:
- `!tower close` passes only by a majority of the active players, never on time alone.
- A player training a skill with no line (Crafting, Fishing) keeps the class line they already wear, so "equip best"
  can upgrade them within that line over stronger plate.
- Tank gear starts with flatter pauldrons at tiers 1 and 2 than the approved concept, to leave room to grow.
- Healer tiers 4 to 8 are all near-white cloth and differ mainly by trim.
- Only Defense counts as the tank path (training "all" cannot be told from Health on the server).

Known gaps:
- Games before 0.9.7 show class gear in the default teal with pauldrons on robes and no head under hats and hoods.
- Fixed 2026-11-21: "Woollys Bell" was created again at every server start; the copies are merged at startup
  (RavenNest 5fc64e18). On production the first start after the deploy merges the copies there: check the log.
- 94 materials of the old animal pack point to a shader that is not in the project (magenta if used).
