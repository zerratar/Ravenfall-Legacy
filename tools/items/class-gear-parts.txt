# Line | ItemType | name after the tier | male model ids | female model ids | HeadMask

# Model ids: the main part first, then the others in the game's order:
#   Chest: torso, shoulder pads, upper arms, elbow pads     Gloves: hands, lower arms
#   Leggings: hips, knee pads                               head pieces: the piece, then head attachments
# A slot the piece has nothing in is named in the HeadMask (NoShoulderPads, NoElbowPads, NoForearms, NoKneePads)
# and still holds a valid index, because games before 0.9.7 read every index and know nothing of the mask.
# On a head piece the HeadMask is what it hides of the player's head: Hair, Brows, Beard, Ears, Head (All = a helmet).
# The first head piece of a line is its main one (the one the review sheets show).
