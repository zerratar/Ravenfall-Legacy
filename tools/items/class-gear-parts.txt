# The class gear's pieces (v0.9.7): what each one is made of, tier by tier. Read by tools/items/class-gear-preview.cs
# and tools/items/class-gear-icons.cs; the server's item rows (RavenNest's GameData.ClassGear.cs) must say the same
# (model ids and HeadMask). docs/class-gear-design.md has the table for people.
#
# Line | ItemType | name after the tier | male model ids | female model ids | HeadMask | tiers
#
# Tiers: the tiers the row is for ("3-5", "8"); every tier when empty. Each piece has exactly one row for each tier.
#
# Model ids: the main part first, then the others in the game's order (SyntyPlayerAppearance.EquipArmor):
#   head pieces: the piece, then any number of head attachments (0 to 12: plume, wings, antlers, crown, cross ...)
#   Chest:       torso, shoulder pads, upper arms, elbow pads, then what is worn on the back (0 to 9: Chr_BackAttachment_01
#                to 10; left off on a player who wears a cape)
#   Gloves:      hands, lower arms
#   Leggings:    hips, knee pads, then any number of things on the belt (0 to 11: Chr_HipsAttachment_01 to 12)
#   Boots:       legs
# A game before 0.9.7 reads all of a head piece's ids, a chest's first four and the leggings' first two as part indices,
# and only parses the rest as numbers. So every id is a whole number, and those positions always hold a real index:
# a slot the piece has nothing in is named in the HeadMask (NoShoulderPads, NoElbowPads, NoForearms, NoKneePads) and
# still holds one (leggings with a belt and no knee pads say knee pad 10, the least seen, and NoKneePads).
# On a head piece the HeadMask is what it hides of the player's head: Hair, Brows, Beard, Ears, Head (All = a helmet).
# The first head piece of a line is its main one (the one the review sheets show).
#
